# AI Landscape

New names show up every week. This is a map of what’s loud in AI now — and what still matters from earlier rounds.

Personal notes — not rankings, endorsements, or affiliations.

## Buckets

- **Model providers** — the brains harnesses call
- **Terminal agents** — CLI/TUI harnesses
- **IDE agents** — editors and extensions with agent loops
- **Cloud agents** — async agents that often return a PR
- **Personal / always-on agents** — messaging-native assistants (e.g. OpenClaw)
- **UI & app builders** — design canvases and prompt-to-app tools
- **Gateways & SDKs** — routers, proxies, and kits for building with models
- **Image** — text-to-image and generative stills
- **Video** — text/image-to-video, creative suites, avatar tools

## Repo

- `README.md` — why this exists
- `index.html` — the notes page (HTML/CSS/JS in one file)
- `.nojekyll` — lets GitHub Pages serve the site without Jekyll

## Publish (GitHub Pages)

1. Push this repo to GitHub.
2. **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**
4. Branch: `main` / root (`/`)
5. Save — site will be at `https://<user>.github.io/ai-landscape/` (or your custom domain)

Deep-link a category with `?cat=terminal` (or `ide`, `cloud`, `personal`, `ui`, `models`, `gateways`, `image`, `video`).

Update the page as the landscape moves. Last updated: Aug 2026.
